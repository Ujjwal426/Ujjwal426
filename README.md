## 🚀 What I've shipped

| Area | Impact |
| :-- | :-- |
| 💸 **Payments** | Idempotent Kafka consumer ingesting 5,000-row batches. Re-uploads never pay twice (10K–20K txns/month). |
| 🔁 **Fault tolerance** | Crash-safe batch payouts that apply offer rules, credit cashback, reverse refunds and auto-restart stuck runs. |
| 🌍 **Geospatial pricing** | PostGIS service-area lookups and incremental price publishing guarded by a Redis distributed lock. Live in the **UAE and Philippines**. |
| 🎟️ **Bookings** | Redis slot locking (5-min TTL) plus Stripe idempotency keys: no double bookings, no double charges. |
| 🧩 **Rule engine** | No-code, server-driven offer builder so banks launch offers without engineers. |
| 🤖 **AI** | OpenAI-powered rule creation cut offer setup from **~20 min to under 3**. |
| ⚙️ **CI/CD** | Build-once, deploy-many GitHub Actions pipeline: CI time down **63%** (19 → 7 min). |
| 🛡️ **Reliability** | Post-release crashes down **~80%** across 227 pages via a guarded chunk-reload strategy. |

## 🧪 Featured project: AI Workflow Platform

> A drag-and-drop workflow builder with a Go execution engine that streams live status over WebSockets.

- 🖱️ **React Flow editor** with live connection validation, undo-safe state and autosave
- ⚡ **Go (Fiber) + PostgreSQL engine** streaming per-node status, logs and retries over WebSockets
